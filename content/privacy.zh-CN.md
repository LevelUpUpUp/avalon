# Avalon 隐私政策

更新日期：{{last_updated}}

Avalon 由 {{developer_name}} 开发和提供。本政策适用于 Avalon Mac 应用及随应用提供的手机浏览器访问功能，说明本机资料库如何处理数据，以及我们在你联系支持或访问本网站时如何处理信息。

## 1. 数据保存在你的设备上

Avalon 是本地照片与视频管理工具。资料库数据保存在运行 Avalon 的 Mac、你选择的磁盘或备份位置；搜索模型在本机运行。当前版本不提供开发者托管的云图库，不会自动向开发者或第三方 AI 服务上传你的照片、视频、搜索词或资料库。

“本地处理”不代表数据不会离开这台 Mac。你授权的局域网用户、你创建的分享链接，以及你主动下载、导出或备份的操作，可能使内容到达其他设备或接收者。

## 2. 本机处理的数据和用途

- **照片与视频**：处理你选择目录中的文件、你导入或上传的内容，用于浏览、播放、整理、下载、导出和备份。
- **文件与照片元数据**：包括文件名、路径、大小、时间、内容校验值、磁盘和目录信息，以及文件中已有的 EXIF（例如相机信息、拍摄时间和 GPS 拍摄位置）。用于识别文件、去重、排序、地图展示、查找和备份管理。拍摄位置来自导入文件的元数据，不等同于持续获取你的实时位置。
- **派生数据**：包括缩略图、预览、搜索向量、索引和生成的相册内容，用于显示、语义搜索和相册制作。搜索模型使用本机资料库进行推理；当前版本不会将这些内容发送给我们用于训练模型。
- **账号与资料库操作**：包括你在本机资料库建立的用户名、密码哈希、账号角色、会话和权限记录，以及收藏、标签、相册和分享记录。用于登录、访问控制和保存你的操作。服务端账号数据库保存不可逆密码哈希；如果你在 Mac 客户端选择“记住密码”，登录密码会另行保存在系统安全存储中（macOS 钥匙串）。应用客户端或手机浏览器会保存维持登录所需的状态，Web 使用登录所需的会话 Cookie；设置分享密码时，分享页面可能在当前浏览器会话中保存该密码以支持刷新。这些机制用于登录和分享访问，不用于广告跟踪。
- **运行与诊断信息**：包括应用设置、版本、任务状态、随机安装标识和运行日志。用于启动、故障排查和本机任务管理。日志可能包含文件路径、时间、错误信息和操作记录，不会自动发送给开发者。应用中的“复制支持信息”仅复制版本和平台，不自动包含照片、日志、路径或凭据。

当前发布包不提供人脸识别功能。上述数据说明不意味着当前版本会建立人脸识别模板；如未来增加这一功能，我们会更新说明并提供相应设置。

## 3. 目录权限和局域网访问

你通过系统目录选择器授予文件访问权限，可以在应用的“目录访问权限”中管理授权；适用的系统权限也可在 macOS 系统设置中管理。撤销权限会限制后续访问，但不会自动擦除已经生成的缩略图、索引、导入副本或备份。

手机浏览器和其他获准用户可以连接运行 Avalon 的 Mac，根据资料库权限浏览、上传或管理内容。资料库管理者可以管理账号和权限，并控制本机数据。请只向信任的人授权。

当前默认局域网访问使用 HTTP，不提供传输链路加密；密码哈希存储不能保护网络传输中的登录请求或内容。请仅在可信网络使用，不要直接将服务端口暴露到公网。你自行配置的网络转发、代理或远程访问会改变可访问范围。

## 4. 分享、导出和第三方

创建分享链接可能使指定内容向持有链接的人开放；接收者可能下载或保存副本。请谨慎选择分享内容和接收者，并在不再需要时撤销分享。撤销链接不会收回已经下载、截图或转发的副本。文件中的拍摄位置等元数据也可能随原文件一同披露。

Avalon 当前版本不包含广告、广告跟踪或第三方行为分析 SDK，不出售你的资料库数据。应用使用的软件组件在本机支持显示、存储和计算，不因你导入资料库而自动向开发者提供资料库内容。

你主动使用的邮箱服务、网站、接收设备或自行配置的外部存储服务，按其自身规则处理你发送给它们的信息。系统和应用商店服务由 Apple 按其政策提供；Apple 管理的诊断、下载或支付行为不等同于 Avalon 自动上传资料库。

## 5. 数据保留、删除和权限撤销

本机资料库数据通常保留到你通过相应功能删除、重置，或自行清理有关文件为止。卸载应用不一定清除应用数据、源文件、上传原件或备份。

- **删除我的账号**：在“隐私与支持”中发起并用当前密码确认。账号立即停用、会话撤销；个人收藏、相册、标签、分享和权限等关联记录随后清理。请保持 Mac 服务运行，直到后台清理完成。共享资料库中的原件、公共元数据和公共索引由本机管理者保留，不会因删除某个账号而一并删除。
- **删除照片或视频**：通过应用的文件删除功能处理相应文件和副本，并检查所选删除范围。离线磁盘、回收站、独立备份及已向外发送的副本可能仍保留内容，需要另外确认或清理。
- **重置本机资料库**：本机管理员可在系统身份验证后删除资料库账号、数据库、搜索索引、缩略图、分享缓存和日志，并清除目录授权。该操作保留上传原件、用户选择的源文件和备份。后续需重新设置管理员、授权目录和导入。
- **撤销访问**：你可以撤销目录授权或分享；管理员可以管理账号、会话和资料库访问权限。撤销权限本身不会清除已形成的独立副本。

开发者无法直接读取或远程删除你的本机资料库。如需处理共享内容，请使用本机功能或联系资料库管理者；如需删除此前发送给我们的支持信息，请联系下方邮箱。

## 6. 联系支持时的信息

联系 {{contact_email}} 时，我们会收到你主动提供的邮箱地址、问题描述和附件，只用于回复、排查问题和处理请求。请尽量提供经过遮盖的错误信息，不要发送密码、会话凭据、完整私密照片或完整资料库。

支持通信会通过你选择的邮箱服务和我们用于接收邮件的服务处理。问题处理期间及后续必要的跟进期间，我们可能保留相关通信；不再需要时删除，适用的法定保留义务除外。你可以请求删除已提供的支持信息；我们会核实请求并在适用法律要求的期限内处理。

## 7. 本网站的访问

本隐私和支持网站使用 GitHub Pages 托管。页面本身不加入统计脚本、广告、Cookie、外部字体或第三方嵌入内容。为了传输网页和保障服务运行，托管服务 GitHub 仍可能按其政策处理 IP 地址及访问日志等网络信息。访问本站不会向网站提交你的 Avalon 资料库。

详情可阅读 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。点击外部链接后，目标网站适用其自身隐私政策。

## 8. 你的选择和请求

你可以通过本机功能查看、下载或导出内容，修改资料库信息，管理权限，撤销分享，删除账号，或由本机管理员重置资料库。涉及其他人的照片或共享资料库时，请尊重相关人员的隐私和授权。

如你所在地区的法律赋予你访问、更正、删除、限制处理、反对处理或获取数据副本等权利，可向我们提出与我们持有的信息有关的请求。本机资料库的操作需由你或有权限的管理者执行；撤销授权不影响撤销前已经进行的处理。

## 9. 政策更新与联系

如果数据处理方式或相关功能变化，我们会更新本政策和更新日期；重大变化会通过适当方式说明，并在需要时取得授权。
